# 设备档案表 —— 身份 → 安装方案 → 客户备注
# 格式: 身份|方案名|备注
# 身份 = 盒子序列号（不区分大小写）或 MAC（去掉冒号），先查序列号再查 MAC
# 方案名对应 /srv/tvupd-priv/plans/<方案名>.txt，没有匹配到就走 default
# 备注自由填写（客户名/地址/电话），会随心跳一起记入 access.log，便于定位客户
# 增删改盒子：控制台「盒子与方案」页编辑保存即可，盒子 10 分钟内自动切换，无需碰盒子

# ===== 示例（按需修改/删除）=====
# 0000000000000000EXAMPLE01|default|示例-自家测试盒
